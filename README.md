# InfClaw для Windows

InfClaw соединяет OpenClaw с вашим аккаунтом ChatGPT. Вы отправляете задачи привычным способом — например, через Telegram, — а InfClaw выполняет запросы в ChatGPT и возвращает результаты через OpenClaw.

## Что умеет InfClaw

- **Работать с OpenClaw и Telegram.** Выполнять задачи из подключённого OpenClaw, в том числе из вашего Telegram-диалога с ним.
- **Выполнять несколько задач.** Поддерживать параллельные чаты и отдельное выполнение заданий по расписанию OpenClaw.
- **Продолжать длительные задачи.** Автоматически переходить к следующему этапу с сохранением результатов предыдущего.
- **Работать с файлами.** Передавать вложения, обрабатывать PDF и изображения, возвращать подготовленные файлы.
- **Использовать проекты ChatGPT.** Создавать рабочие чаты в выбранном проекте.
- **Показывать ход работы.** Следить за текущей сессией, событиями и историей активности в одном окне.
- **Помогать с подключениями.** Проверять состояние ChatGPT и OpenClaw, показывать диагностику.
- **Работать в фоне.** Сворачиваться в область уведомлений и запускаться вместе с Windows.
- **Управлять лицензией и обновлениями.** Показывать срок подписки и устанавливать новые версии из приложения.

## Как начать

1. Скачайте **InfClaw-0.8.4-Setup.exe** на [странице загрузок](https://github.com/elisey-pro/infclaw-releases/releases/latest).
2. Установите и запустите InfClaw.
3. Войдите в ChatGPT и настройте подключение к OpenClaw.
4. Активируйте лицензию InfClaw и отправьте первую задачу.

## Требования

Windows 10 версии 2004 или новее либо Windows 11, 64-разрядная система, интернет, аккаунт ChatGPT и настроенный OpenClaw.
